Install in a few steps.

  1. Unzip the download. Move Hush.app to your Applications folder.
  2. Quit other mic-mute utilities. They can conflict with Hush.
  3. Open Hush. Look for the microphone in your menu bar. Hush has no Dock icon.
  4. If macOS blocks it: after you try to open Hush, check System Settings → Privacy & Security. If you trust this copy, use Open Anyway and confirm. Follow Apple’s current opening guidance. Managed Macs may prevent exceptions.

Meet your mute button.

Press Control + Option + M from any app. Left-click the menu icon to toggle. Right-click for devices and Settings. Hold shortcuts are optional and can be set in Settings.

What is different in this beta?

Native Shortcuts actions may not run in the ad-hoc build. Use the URL commands below instead. Intel Macs, broader device compatibility, and a fresh quarantined install on another Mac remain unverified.

In Shortcuts, use Open URLs with hush://toggle, hush://mute, or hush://unmute. The app must be installed first.

A note about mic access.

Basic mute controls need no microphone or Accessibility permission. Optional levels and recording tests ask for mic access. Read the privacy details.

Feedback and fixes.

Report a problem in the public issue tracker. Include your macOS version and input device. Do not include private recordings or app history.
